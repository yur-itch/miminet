Closes #539

## Проблема
При регистрации через Яндекс не подтягивается аватар и не создаётся пример сети, хотя при регистрации через VK и то и другое есть.

## Решение
- Из `vk_callback` вынесены `download_avatar()` и `create_example_network()`, `yandex_callback` использует их же. Поведение VK не изменилось.
- Аватар Яндекса берётся из ответа `login.yandex.ru/info`: `default_avatar_id` → `https://avatars.yandex.net/get-yapic/<id>/islands-200`. Если `is_avatar_empty` (заглушка Яндекса), остаётся `empty.jpg`. Формат по [документации Яндекс ID](https://yandex.ru/dev/id/doc/ru/user-information).

## Проверка
- `front/tests/test_yandex_registration.py` (8 тестов, внесён в `front_coverage.yml`): URL аватара, фолбэк при сетевой ошибке, новый пользователь получает аватар и пример сети, вернувшийся пользователь второй пример сети не получает.
- Сквозная проверка на локальной БД, подменён только обмен OAuth: новый пользователь создан, аватар скачан с `avatars.yandex.net` (9229 байт), пример сети «Свитч и хаб» создан, редирект на `/home`.

## Важно для прода
`default_avatar_id` приходит, **только если у OAuth-приложения включено право «Портрет пользователя»**. Если на проде его нет, аватары не появятся и после этого PR. Надо проверить настройки приложения в кабинете Яндекс OAuth.

## Замечено попутно (не в этом PR)
1. `email=id_info.get("default_email", "")` при `User.email unique=True`: второй пользователь без email получит `IntegrityError`. Кроме того, Яндекс, в отличие от VK, не связывает аккаунт по email.
2. По умолчанию `avatar_uri = "empty.jpg"`, и шаблон рисует `<img src="/avatar/empty.jpg">`, а этот файл на проде отдаёт 404. Похоже, у всех пользователей без аватара в шапке сломанная картинка.
